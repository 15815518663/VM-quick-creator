# VM-quick-creator
VM Quick Creator


介绍
中文：  
一键快速生成虚拟机启动脚本的轻量工具，为虚拟机爱好者简化创建流程，支持自定义配置，提供完整安装卸载方案，附带全部源代码。


English:  
A lightweight tool that quickly generates virtual machine startup scripts. Simplifies the creation process for virtual machine fans, supports custom configuration, provides complete installation and uninstallation solutions, and includes full source code.


下载
中文：  
在右侧 Releases 页面可以下载最新版安装包，源代码已完整包含在本仓库中。


English:  
Download the latest installer from Releases. Full source code is available in this repository.


编译
中文：  
1. 克隆仓库：git clone https://github.com/15815518663/VM-quick-creator.git
2. 使用 CMake + C++ 编译器编译源码
3. 可使用 Inno Setup 重新打包生成安装包


English:  
1. Clone the repo: git clone https://github.com/15815518663/VM-quick-creator.git
2. Use CMake + C++ compiler to compile source code
3. Package to installer with Inno Setup (optional)

紹介
日本語:  
仮想マシンの起動スクリプトをワンクリックで素早く生成する軽量ツールで、仮想マシン愛好家のために作成プロセスを簡素化します。カスタマイズ設定に対応し、完全なインストール・アンインストール方案を提供し、すべてのソースコードが付属しています。


ダウンロード
日本語:  
右側のReleasesページから最新のインストールパッケージをダウンロードできます。ソースコードはこのリポジトリに完全に含まれています。


ビルド
日本語:  
1.  リポジトリをクローン：git clone https://github.com/15815518663/VM-quick-creator.git
2.  CMake + C++コンパイラでソースコードをコンパイル
3.  Inno Setupでインストールパッケージを再パッケージ化可能（任意）
